## 📝 Post Text (Copy-Paste Ready)

```
🚀 I just built an AI that can READ entire GitHub repositories.

Over the last week, I built a **Code Documentation Navigator** using:
• RAG (Retrieval-Augmented Generation)
• Tree-sitter
• ScaleDown prompt compression

It allows you to ask things like:
"Where is authentication implemented?"
"How does this project use the database?"

and get intelligent answers with file references — even for very large codebases.

The key challenge was LLM context limits.
So I used ScaleDown to compress large code files (5000 → 800 tokens) while preserving meaning.

This reduced:
• Token usage by 75%
• Cost
• Latency
while keeping accuracy high.

I tested it on 3 open-source repos and it works 🔥

GitHub: https://github.com/[YOUR_USERNAME]/rag-codebase-explorer

Building this taught me a lot about:
• RAG
• Code embeddings
• Prompt compression
• Developer tools AI

More coming 👨‍💻🚀
```
